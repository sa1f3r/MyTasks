# My Tasks

Простой и настраиваемый плагин для трекинга задач, имеющий несколько режимов отображения (канбан, древо, календарь)

Так же позволяет вручную кастомизировать и настраивать статусы — можете пользоваться "из коробки" (с базовыми статусами)
или удалять/добавлять свои статусы, настраивая им цвета, обозначения и теги.

Тасктрекер сохраняет задачи в один файл в виде буллет-списков

## Установка
1. Откройте Настройки -> Сторонние плагины.
2. Включите сторонние плагины и найдите этот плагин в каталоге.
3. Нажмите Установить.
